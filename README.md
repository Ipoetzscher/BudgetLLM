# Budget Allocation Agent

An AI-powered budgeting assistant that automatically categorizes credit card transactions while learning from user corrections over time.

## Motivation

Manually categorizing hundreds of transactions each month is tedious.
This project uses an LLM together with persistent memory to automate the process while keeping the user in control.

## Features

- [x] AI categorization
- [x] Merchant normalization & sanitization of sensitive bank info
- [x] Persistent memory
- [x] Human review interface
- [ ] Unit tests
- [ ] Documentation
- [ ] Deployment
